# Kristian Frroku – Logistics & Operations Portfolio

A clean, professional, and fast-loading digital CV tailored for logistics, dispatching, and supply chain operations. 

> [Live Site](https://6kristian.github.io/Portfolio/)

## 🚀 Overview

This portfolio is designed to be a grounded, corporate-facing resume website. It avoids heavy, resource-intensive CSS animations (no "AI" glassmorphism or glowing effects) to ensure it loads instantaneously and flawlessly on any browser, mobile device, or older corporate hardware.

### Key Features
* **Zero Dependencies:** Built entirely with semantic HTML5 and clean CSS. No heavy JavaScript frameworks.
* **Corporate Design:** A professional, high-contrast UI tailored for hiring managers in the logistics sector.
* **Fully Responsive:** Adapts perfectly to desktop, tablet, and mobile screens.
* **Working Contact Form:** Integrated with Formspree for immediate lead capture straight to your email.
* **SEO Optimized:** Structured data and meta tags included to accurately index you as a Logistics Professional.

## 🛠️ How to Deploy

Because this site is built purely on static HTML and CSS, deploying it is incredibly simple:

1. **Upload:** Drag and drop the `index.html` file into the root of your GitHub repository (`6kristian/Portfolio`).
2. **GitHub Pages:** Go to your repository settings -> Pages -> Set the source to the `main` branch.
3. **Live:** Your site will automatically build and deploy to your GitHub Pages URL within minutes.

## ✏️ How to Edit Content

If you need to update your experience or add a new job in the future, simply open `index.html` in any text editor (like Notepad, VS Code, or directly in GitHub) and look for the `<section id="experience">`. 

You can easily copy and paste an existing `<div class="exp-item">` block and swap out the text to add a new role!
